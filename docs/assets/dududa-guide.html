群友使用指南

生活在 QQ 群里的 AI 群友

3.1.16 · 非管理员命令与功能全览

01

先叫到我，再开始吧

GET STARTED
  • 群里提问

    @嘟嘟哒 你的问题
    也可用“嘟嘟哒”或“dududa”开头。

  • 使用命令

    /天气 合肥 明天
    或发送 嘟嘟哒 天气 合肥 明天。

  • 私聊交流

    直接说话，命令前缀可省略。
    问问题、发图片、接着上文聊都可以。

02

日常查询与资讯

EVERYDAY & UPDATES

  • /帮助

    以图片查看群友命令、功能与使用条件。

    别名：help · 菜单

  • /在吗

    看看我在不在线；连续刷屏会暂时不回应。

    别名：ping · 在不在

  • /状态

    查看版本、服务时长、当前模型与运行任务。

    别名：status

  • /时间

    上海、洛杉矶、纽约、巴黎时间，自动处理夏令时。

    别名：time · 几点了

  • /天气 [城市] [日期]

    日期可写今天、明天、后天；默认城市合肥。

    别名：weather · 直接提问还可查未来 1–7 天天气、降雨时段。

  • /校车 <条件>

    按校区、路线、日期和时间查询科大校车班次。

    别名：shuttle · 例：校车 明天东区到西区

  • /新闻

    今天的橘鸦 AI 早报：新闻概览与原文链接。

    别名：news · 早报

  • /状态告警

    查询 OpenAI、Anthropic、DeepSeek 服务状态。

    别名：llm status · llm状态

  • /博客 <公司>

    OpenAI 或 Anthropic 官方博客最新 5 条。

    别名：blog · 公司简写：O/、O\、A/、A\

  • /播客 <公司>

    OpenAI 或 Anthropic 官方播客、视频最新 5 期。

    别名：podcast · 公司写法与“博客”相同。
03

聊天、记忆与上下文

CHAT & MEMORY

不必把问题写成命令。直接聊天、问代码、请我解释图片或查资料；我能结合引用、发送者身份和近期上下文回答，必要时联网搜索。

  • /总结群聊 [时间范围]

    按话题梳理讨论经过与结论；默认近 3 小时，可写“今日”“近 5h”。长总结以合并转发发送。

    别名：群里最近在说什么 · 近期消息省流 · summary

  • /记住 <内容>

    把指定内容保存为当前会话的显式记忆。

    别名：remember · 不同会话的记忆相互隔离。

  • /记忆 [关键词]

    按关键词查找记忆；不写关键词时看最近记录。

    别名：memory

  • /忘记 <编号>

    删除自己在当前会话写入的那条记忆。

    别名：forget

  • /取消

    取消当前会话正在执行或排队的任务。

    别名：cancel

  • /新对话

    结束当前任务，重新开始 AI 对话；显式记忆保留。

    别名：new
04

创作，也慢慢熟悉彼此

CREATE & CONNECT

  • /生图 <描述>

    画一张新图，也可附带或引用参考图进行创作。通常需要 1–3 分钟。

    别名：画图 · draw · image gen · img · imggen · img gen

  • /表情合成 <表情1> <表情2>

    将两个受支持的表情合成为 Emoji Kitchen 图片。

    别名：emoji · 直接发送两个表情作为参数。

亲密度 · 每一次相处都会留下印象

亲密度 ≥ 50 可查询与设置

  • /亲密度

    显示群排行：Top 5 与 Low 5，人数较少时合并展示。

    别名：好感度；也可用 亲密度排行 · 亲密度 排行 / 排名 / 榜

  • /亲密度 all

    显示本群完整排行图片，含名片、QQ、分数与档位。

    参数同义：全部 · 全员 · 所有人 · 全部人

群榜统计最近 90 天在该群与我互动过的人；普通用户私聊时显示其最近活跃群。分数按 QQ 共享，同群换号不丢记录；恰好 50 分也能查询。

  • 特别讨厌
  • 讨厌
  • 反感
  • 普通
  • 好感
  • 喜欢
  • 特别喜欢
个人设置 · 只操作自己的资料，不改变群名片

  • /亲密度 设置 [查看]

    查看本人在当前会话的称呼、偏好与约定。

    /亲密度 设置 称呼 <名字> 设置认可的称呼。

  • /亲密度 设置 保存 <偏好|约定> <内容>

    明确同意保存内容，只在当前会话使用；保存约定需已建立闺蜜关系。

  • /亲密度 设置 关系卡 [基本|特别]

    查看关系卡；设置 样式 <基本|特别> 保存卡片样式。需要已建立关系。

    设置 特别称呼 <名字> 与特别样式还需亲密度 ≥ 80。

  • /亲密度 设置 删除 <编号|称呼|特别称呼|全部>

    删除本人设置；“全部”清除本人各会话的设置与约定，不清除分数或关系。

    也可通过 /亲密度 设置 问候 … 管理问候。
关系与问候 · 由本人确认，不自动订阅

  • /闺蜜 [申请|确认|状态|关系卡|解除]

    亲密度严格大于 50 才可建立关系；申请后需本人在同一会话内确认，10 分钟有效。

    关系卡也可写“卡”；关系非恋爱、非排他，建立后不会自动开启问候。
    也可 @ 我说：做闺蜜 · 和我做闺蜜 · 我们做闺蜜吧 · 我们可以做闺蜜吗 · 可以和我做闺蜜吗。

  • /申诉 [说明]

    请求管理员复核误判，不会自动加分；同一人仅保留一条待处理申请。

    /申诉 状态 查看进度；处理结论回提交申诉的会话查看。

  • /问候 早安 <HH:MM>
    /问候 晚安 <HH:MM>

    亲密度 ≥ 50 可分别开启。默认关闭，时区为上海；例如 /问候 早安 08:00。

  • /问候 生日 <MM-DD> <HH:MM>
    /问候 纪念日 <YYYY-MM-DD> <HH:MM>

    亲密度 ≥ 80 且已建立关系时可单独开启。日期由本人提供，不会自动公开生日。

  • /问候 [状态]
    /问候 确认 <早安|晚安|生日|纪念日>

    查看订阅；换会话开启时，需在新会话内确认替换，每种问候只保留一个目标。

  • /问候 关闭

    关闭全部本人问候；也可分别使用“关闭早安 / 关闭晚安 / 关闭生日 / 关闭纪念日”。

群里开启就在该群 @ 本人，私聊开启才发私聊；群目标须同时允许服务和主动消息。每人每天每种最多一次，不向共同群广播；失去权限会暂停，恢复后需重新开启。

关系降至 50 分及以下会暂停亲密权益与问候；关系仍保留。严重负面状态会限制普通回复和娱乐功能，但解除关系、关闭问候、删除本人数据与申诉在任何分数下均可使用。

05

科大校园助手

CAMPUS QUERIES

不用背命令，直接说想查什么。以下查询由已接入的校园服务提供。

  • 课程口碑 · iCourse

    找课程和老师，查看课程详情、评价、排行与公开统计。

    “这门课大家评价怎么样？”

  • 校园通知 · NotifAI

    检索通知与详情，查看分类、来源、日历、截止日期及同步统计。

    “这周有哪些快截止的通知？”

  • 学期与开课

    查询学期列表、全校开课信息，按条件筛选课程。

    “这学期开了哪些机器学习相关课程？”

  • 考试与教学日历

    查询官方考试安排、教学日历与重要日期。

    “查一下考试安排和教学周历。”

  • 培养方案资料

    按年级、专业检索公开方案，比较课程要求与变化；使用资料快照。

    “这个专业不同年级的培养方案有哪些区别？”

  • 第二课堂

    查活动、详情与系列场次，按模块、部门和标签筛选，也可检查服务连接。

    “最近有哪些第二课堂活动？”

这些资料请在私聊中问我 私聊限定 · 只读缓存

  • 学校与学院公告

    检索学校主页公告、学院通知，附摘要、来源和已有附件链接。

  • 图书馆开放时间

    按校区或地点查业务内容、工作日 / 周末时段及联系电话。

  • 校园生活参考

    查餐饮、活动、学习去处，按校区、餐次、价位筛选；不是实时营业信息。

  • 本科专业设置

    按年份、学院查专业、代码、学位与停招标记；不等同于实时培养方案审核。

还可以问“你能查哪些校园服务？”。资料可能来自缓存或历史快照，以返回的来源、更新时间和学校正式页面为准；本页校园查询不执行选课、报名或提交操作。

06

自动小功能与课程订阅

AUTOMATIC FEATURES

不用每次 @ 我；满足条件且功能已开启时自动工作。

  • 链接解析

    为 B 站、公众号、X、arXiv、bioRxiv / medRxiv、Nature、Science 及官方博客 / 播客链接补标题、干净链接与封面。

  • 小红书归档

    分享笔记后，归档正文及无水印图片 / 视频，并以合并转发发出；受来源访问权限影响。

  • 猫图点爱心

    识别群聊图片里的猫，给原消息贴爱心回应；每群每小时最多 30 次。

  • 复读机

    群友连续发出相同文字、图片或表情时，跟着复读一次。

  • 主动参与聊天指定群

    在允许的群里结合上下文适时接话；没有值得说的就保持安静。

  • 防撤回转发启用群

    收到撤回事件时，将缓存到的原消息文字、图片与发送者信息转回群中。

  • 服务故障 / 恢复通知需配置

    检查 OpenAI、Anthropic、DeepSeek 的状态变化，向配置的接收目标推送。

  • 定时 AI 早报默认关闭

    启用并配置接收目标后，按设定时刻推送橘鸦 AI 早报；手动查新闻不受此开关限制。

  • BB 课程通知授权订阅者私聊

    自动检查当前学期的作业、公告和课件，用 Luna 提取课件内作业、截止依据及摘要，推送提醒与图文日报；空课程继续检查但不展示。

    /课程 [学号] 列表 · 今日 · 状态
    /课程 完成 学号:C1 · /课程 恢复 学号:C1
    /课程 截止 学号:C1 YYYY-MM-DD HH:MM

    需由账号持有人授权配置。账号之间独立，只更改本地任务状态，不提交作业；主人省略学号时仍操作原账号。

07

授权群的用量查询

Sub2API · 仅授权范围

无需管理员身份，但必须在已授权的会话中使用。用量专用群可能只开放这组命令。

/sub2api <子命令>　入口别名：/sub2、/用量

  • help

    查看本模块帮助与参数说明。

    同义：帮助

  • overview

    合并查看今日、当前计费轮、历史累计与上游账号。

    同义：概览 · 汇总

  • today

    今日用量与用户排名。

    同义：今日 · 今天

  • total

    历史累计用量。

    同义：历史 · 累计

  • range <开始日期> <结束日期>

    指定日期区间的用量汇总。

    同义：范围 · 区间

  • trendtotal [Nd]

    总 Token 用量趋势图。

    同义：trend · 总趋势

  • trenduser [sum] [Nd]

    用户用量趋势；加 sum 看区间累计趋势。

    同义：用户趋势

  • users [开始日期 结束日期]

    用户用量排名，不写日期时查看今日。

    同义：用户 · 排名 · 排行

  • models [开始日期 结束日期]

    按模型查看用量，不写日期时查看今日。

    同义：模型

  • accounts

    上游账号状态列表。

    同义：账号 · 账户

  • account <ID>

    单个上游账号的状态与今日用量。

    同义：单账号 · 单账户

  • status

    检查用量服务的连接和统计状态。

    同义：状态 · 连接

示例：/用量 今日、/sub2api trend 7d。日期格式为 YYYY-MM-DD，Nd 表示近 N 天；统计范围与显示条数遵循授权配置。

小提示 · 把问题说清楚，比把命令背下来更重要

<参数> 表示需要填写，[参数] 表示可以省略；发送时不带括号，参数之间用空格分隔。群里未知的斜杠指令会被忽略。

仅在已接入的群和私聊中服务。默认频率限制为每 5 分钟群聊 30 次、私聊 50 次主动回复；功能受会话配置与数据源状态影响。本页不包含管理指令及主人专属的研究生作业、周报操作。
