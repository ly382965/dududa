# 嘟嘟哒亲密度与闺蜜规则

> 2026-10-20，3.1.15 实现规范，替代此前讨论方案。部署、数据和回滚见[运维手册](../operations/v3.md#亲密度affinity隐藏机制)。

## 1. 分数与档位

普通用户初始 0 分，范围 −100～100，按 QQ 号跨群、跨机器人账号共享。使用原始小数分判定权限，不先四舍五入。

| 原始分数 s | 档位 | 行为 |
| --- | --- | --- |
| −100 ≤ s ≤ −80 | 特别讨厌 | 默认固定回复「我讨厌你，不要和我说话。」 |
| −80 < s ≤ −50 | 讨厌 | 冷淡简短，部分娱乐功能不可用 |
| −50 < s < −20 | 反感 | 保持距离，不进行亲密互动；普通功能可用 |
| −20 ≤ s ≤ 20 | 普通 | 默认人设与标准功能 |
| 20 < s < 50 | 好感 | 更热情、适度接梗，不能使用 `/亲密度` |
| 50 ≤ s < 80 | 喜欢 | 可用 `/亲密度` 和个人隐藏设置；严格大于 50 才可建立闺蜜 |
| 80 ≤ s ≤ 100 | 特别喜欢 | 更亲近，开放特别称呼、关系纪念卡和纪念日问候 |

边界：−80 属于特别讨厌，−50 属于讨厌，±20 属于普通，50 属于喜欢，80 属于特别喜欢。喜欢不等于管理员权限，冷淡不等于辱骂或故意答错。

## 2. 群聊优先与负面限制

- **以群聊 @ 为主，私聊也可用。**用户 @ 嘟嘟哒或使用明确指令；亲密度、关系操作的定向回复及主动问候在群内真实 @ 本人一次，不 @ 全体。未叫到 bot 的普通群消息不触发拒答。
- 特别讨厌档对聊天、普通指令、私聊请求默认固定拒答，由宿主直接生成，不调用聊天模型或目标功能。判断使用本条消息进入时的分数，当日加分不能绕过本条限制；仍受防刷保护。
- 讨厌档禁用本人请求的娱乐绘图、Emoji Kitchen、点爱心和定向陪玩；保留原本有权限使用的天气、课程、资料查询、链接解析和基础问答。取消旧版随机拒答，改为明确功能限制。
- 不能因一个人的分数关闭全群功能；已有作业、课程等重要通知不因降分取消，仍按原有授权和退订规则发送。
- 关闭问候、解除关系、删除本人记忆、误判申诉在任何分数下均可用；明确的人身安全紧急求助不走固定拒答。

## 3. `/亲密度` 与隐藏设置

- **s ≥ 50 可用 `/亲密度`，恰好 50 可以。**已有别名使用同一门槛。低于 50 明确请求该功能时回复「暂时不能使用这个功能。」；特别讨厌档优先固定拒答。
- 群内默认显示本群最近 90 天互动成员的 Top 5 + Low 5，不超过 10 人合并展示；`/亲密度 all` 显示本群全部已记录成员，不混入其他群。私聊默认使用本人最近活跃群，没有记录则提示暂无排行。
- `/亲密度 设置` 是聊天里的个人隐藏控制台：设置本人称呼、问候、关系卡样式，查看或删除本人明确保存的偏好与约定。**不新建网站，不开放运维后台。**
- 降到 50 以下暂停新增和修改，退出、退订和删除入口仍可用。隐藏设置不能查看他人私聊、记忆、扣分流水或凭据，也不修改 QQ 群名片。
- Web/CLI 文字帮助不展示关系机制；QQ 完整功能海报列出非管理员命令与使用门槛。日常聊天不播报分数和加减分；正式指令输出例外，不要求模型否认已经展示的机制。

设置示例：`/亲密度 设置 称呼 小明`、`/亲密度 设置 保存 偏好 喜欢简短回答`、`/亲密度 设置 保存 约定 考完试休息一天`、`/亲密度 设置 关系卡`、`/亲密度 设置 删除 <编号|称呼|特别称呼|全部>`。保存内容仅在当前会话使用；小约定和关系卡需要已建立关系，特别称呼与特别样式还需要特别喜欢。

## 4. 闺蜜关系

- **s > 50 才可建立，恰好 50 不可以。**群聊、私聊均可，不要求转私聊，不增加连续打卡或互动天数条件。
- `/闺蜜` 或明确的「做闺蜜」请求发起申请；bot 说明后，由本人在同一会话发送 `/闺蜜 确认`。申请 10 分钟有效，确认时重新检查分数。
- 关系按 QQ 号全局唯一，换群或换机器人账号不重复建立。关系非恋爱、非排他，可以有多位闺蜜；建立关系不加分，不自动开启问候。
- 权益：认可的昵称、关系卡、本人确认保存的小约定；特别喜欢且已建立关系时，增加特别样式和自愿开启的生日、关系纪念日问候。
- s ≤ 50 时保留关系记录，暂停亲密权益和问候；恢复 s > 50 后恢复关系权益，问候必须重新开启。s < 80 暂停特别喜欢专属功能，不删除已保存数据。
- `/闺蜜 解除` 随时取消申请或解除关系，并关闭关系专属推送；不扣分、不挽留、不向其他群公告。
- 群里申请就在当前群确认；私聊建立不主动向群里公布。跨会话关系有效，但私聊约定、生日等信息不能未经同意带到群里。

## 5. 早安、晚安与纪念日

- s ≥ 50 可订阅早晚问候，不强制要求闺蜜关系；已有闺蜜关系若处于暂停状态，问候也暂停。**所有主动问候默认关闭。**
- `/问候 早安 08:00`、`/问候 晚安 23:00` 分别开启；`/问候 状态` 查看；`/问候 关闭早安`、`/问候 关闭晚安`、`/问候 关闭` 分别关闭。默认时区 Asia/Shanghai。
- **默认发送到开启指令所在会话：群里开启就在该群 @ 本人，私聊开启才发私聊。**每种问候只保留一个目标；换会话开启前用 `/问候 确认 早安` 等在新会话确认替换，十分钟有效，不向所有共同群广播。
- 每个用户、每个当地日期、每种问候最多一次，跨群、跨账号去重。群目标必须同时在 `allowed_scopes` 和 `proactive_scopes`；私聊目标必须在 `allowed_scopes` 且为本人。管理员或该群管理员可用 `/问候 群关闭|群开启` 抑制或恢复本群问候，群开启不扩大运维白名单，也不恢复已有停订。
- 投递前复查分数、关系状态、订阅及目标权限。降分、用户退群、bot 退群或目标失效则暂停，不擅自改发私聊；重新满足条件后也不自动恢复订阅。
- 错过计划时间超过 15 分钟跳过，不补发订阅前的历史问候；发送结果不确定不自动重试。退订会取消待排队、已领取但尚未授权的任务；最终发送授权后属于已派发，无法撤回网络中已经开始发送的消息。
- 内容简短，使用认可的昵称和获准使用的偏好，不编造作息或位置。未回复不扣分，bot 自己发出的问候不加分。
- 纪念日问候单独同意、单独选择目标，日期由用户提供，例如 `/问候 生日 05-20 08:00`、`/问候 纪念日 2026-10-20 08:00`；分别以 `/问候 关闭生日`、`/问候 关闭纪念日` 退订。默认关闭，不能因为成为闺蜜就公开生日。

## 6. 计分、管理与迁移

### 计分沿用现有算法

- 正常交流 0～+1，道谢 +1～+2，真诚夸奖 +2～+5；轻度不友好 −2～−5，辱骂 −6～−12，恶意骚扰 −15～−20。索要加分、刷夸奖、单纯使用功能或无法判断均为 0。
- 仅评估发送者对 bot 本人的态度；正常批评、纠错、拒绝邀请、解除关系、没回问候不扣分，引用或转述别人的冒犯不算本人冒犯。
- 每日首次叫到 bot +1；现有频率限制或 ping 防刷触发 −1。相同正向消息 24 小时只计一次，每日奖励及去重跨群、跨账号共享。
- 不增加每日加分上限或打卡要求。从 ±60 继续向 ±100 变化时，变化量乘以 `(100 − |当前分数|) / 40`；反向恢复不打折，最终限制在 −100～100。
- 高于 30 且 14 天未互动，此后每周 −1，最低到 30；低于 0 且连续 3 天没有新冒犯，每 3 天 +1，最高到 0。
- 固定拒答不产生模型评估分，仍记录每日互动奖励及自然恢复。`/申诉` 在任何分数下可提交管理员复核，同一用户仅保留一条待处理申请，不自动加分。
- 申诉处理：本人 `/申诉 状态` 查看进度；管理员仅在私聊使用 `/申诉 列表 [上一页最后编号]`、`/申诉 处理 <编号> <复核结论>`。处理只记录结论，修正分数需另用已有管理员设分命令。

### 管理与数据

- 保留超级管理员固定 120、特殊称呼及现有管理权限，作为七档外例外；免亲密度门槛，但不自动建立关系或订阅问候。管理员身份独立鉴权，不能靠高分获得。
- 保留管理员 `亲密度 查/设/记录` 和超级管理员私聊全局排行能力；普通用户不能查看跨群数据或他人扣分流水。
- 指令、自然语言、工具调用、定时投递统一由宿主校验权限。模型不能自行解锁、确认关系或创建订阅，消息正文不能伪造身份或评分标记；隐藏评分标记不得对外发送。
- 关闭亲密度系统时，停止计分、态度注入、拒答和关系问候，不新增关系或订阅；保留数据，退出与删除仍可用。重新开启后，主动问候需用户重新开启。
- 迁移不重算、不清空现有分数，只更新档位、权限和排行渲染。关系状态、设置、投递记录单独持久化，分数和关系变更保留审计。现有高分用户不自动建立关系或开启问候。

## 7. 验收清单

- 七档边界及边界两侧的小数值正确归档；49.99 不能用 `/亲密度`，50 可以但不能建立闺蜜，50.01 可以。
- 群内定向操作和问候只 @ 本人一次；私聊可用；不同群和机器人账号不重复建立关系或推送。
- 娱乐限制不能通过换说法、工具调用绕过，不影响其他用户和已有重要通知。
- 确认关系、定时投递前重新查权限；降分、退群、退订、换目标、关闭系统和重启均不能导致误发或重复发送。
- 任意分数可退出、退订、删除本人数据；关系恢复不自动恢复问候，私聊信息不泄露到群里。
