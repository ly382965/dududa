# 嘟嘟哒 2.0 作品简介

**作品名称**：嘟嘟哒 2.0——生活在 QQ 群里的 AI 群友

**作品方向**：群聊原生社交智能体；落地于校园生活、教学支持与群体协作

## 她是什么

嘟嘟哒是一个生活在 QQ 群里的 AI 群友。我们希望她像群里一个什么都会一点的人：能接住闲聊，能认真讨论问题，知道什么时候出现，也懂得什么时候闭嘴。大家聊到选课、活动、考试和出行时，她又能找到相应资料，把事情说清楚。

作品围绕一个目标展开：**让 AI 从一次性的问答走向持续的群体参与。** 她需要理解一段对话中的人、事和关系，根据群里的节奏选择参与方式，并逐步拥有稳定的性格、可用的能力和共同的记忆。

## 三条体验主线

### 1. 像群友一样参与对话

群聊里有连续讨论、引用、临时更正，也有一句话换了话题的时刻。嘟嘟哒将上下文感知与 Social Engine 分开设计：前者理解大家在聊什么，后者决定怎样参与。

当前已实现近期群聊上下文读取、引用与更正处理、回复策略，以及按群配置的自动搭话机制。开启自动参与后，普通群消息也可以触发她结合最近讨论接话；参与概率、冷却时间和每小时上限用于调整群聊节奏。明确 @ 时则进入直接响应流程。用户可以用自然语言交流，无需先学习一套命令。

### 2. 做最懂科大的 AI 群友

我们把科大服务拆成智能体可以选择和调用的业务能力。当前已经接入评课社区、第二课堂、教务公开信息、全校开课与考试查询、培养方案资料、校园通知，以及本地校车时刻表。

用户问“线性代数的评价怎么样”，她会寻找课程与教师信息；问“最近有哪些学术活动”，她会转向二课；问到学期安排，则使用教务与校历能力。系统根据问题选择对应服务，管理员可以按群配置插件与能力。进一步自主组合、启停能力的设计将沿统一 Skill 层扩展。

这些校园服务让她在真实生活里有事可做，也使群聊智能体的理解、决策和执行能力可以用具体任务检验。

### 3. 好玩、有性格，逐步成为熟悉的人

嘟嘟哒已有独立的 Persona 人格资产与中文表达规则：日常交流可以轻松，技术问题认真说清楚，语气跟随当前话题。程序还提供 Emoji Kitchen 表情合成及可按群配置的互动插件，让表达更丰富。

我们希望她进一步拥有不同的 OC、说话习惯与表情风格，逐渐认识群友、记住发生过的事情、学会群里的梗。为此，作品已经实现 Memory v2 的会话检索、中文 BM25、记忆写入与生命周期模块，并准备了多 Persona 资产结构。长期记忆接入、多 OC 切换和群友印象是下一阶段的体验建设。

## 支撑体验的智能体系统

嘟嘟哒 2.0 以 Python Runtime 为核心，通过 AstrBot/NapCat 接入 QQ，通过 MCP 和本地能力组件连接校园服务，并由 Vue 3/Node.js 控制台管理。系统将六类职责组合起来：**上下文感知、Social Engine、Memory、模型路由、Skill/MCP 能力体系与人格表达。**

模型路由分别管理“用哪个模型、思考多深、回答多长”；能力层将自然语言需求转换为具体服务调用；回答模块把事实、来源与表达风格组织在一起。Web 控制台复用正式 Runtime，可以查看每次回答所用的模型、能力和耗时，也能按群调整服务与参与方式。

## 使用的模型与 API

本次演示使用 DeepSeek，三个运行档位如下：

| 档位 | 模型 ID | 推理参数 | 用途 |
| --- | --- | --- | --- |
| 快速档 Luna | `deepseek-v4-flash` | `low` | 语义感知、简短交流 |
| 标准档 Terra | `deepseek-v4-flash` | `high` | 校园查询、一般分析 |
| 深度档 Sol | `deepseek-v4-pro` | `max` | 较复杂的论证与比较 |

调用采用 OpenAI 兼容的 Chat Completions 协议，服务地址为 `https://api.deepseek.com`。后端通过 AstrBot `text_chat` 传入模型、提示词、输出额度、`thinking` 与 `reasoning_effort`，接收回答正文和 token 用量。API Key 在部署端配置。

## 创新点与已有成果

- **群聊原生的感知与社交决策。** 把“理解话题”和“决定如何参与”分别建模，结合上下文、群配置与参与节奏组织行为。
- **面向生活任务的原子化能力。** 将课程、活动、通知等服务包装成可独立调用的业务单元，由智能体按需求选择，让能力扩展进入同一条执行流程。
- **人格、记忆与计算策略共同服务体验。** 独立人格资产、Memory 模块和多档模型路由，为持续参与群聊的 AI 角色提供可扩展基础。
- **可观察、可调节的群友系统。** 管理员可以看见一次回答的执行过程，调整不同群的服务、模型和参与方式，使产品能够持续迭代。

当前已完成 QQ 群聊适配、自动搭话执行机制、六类校园服务、三档模型配置与 Web 控制台。真实 DeepSeek Runtime 预览已验证上下文更正、评课、二课、校历等代表任务；100 条固定消息的离线流程验证中，94 条完成响应流程，6 条按入口规则处理，全部预期检查通过。视频展示采用正式 Runtime 的 Web 预览。

嘟嘟哒想成为群里那个平时聊得来、关键时刻帮得上忙、相处久了会越来越熟悉的 AI 群友。科大校园是她开始生活的地方，群体情境理解、人格、记忆和能力系统则支撑她走向更丰富的群聊生活。
