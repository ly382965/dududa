# Architecture Decision Records

ADRs record decisions that constrain multiple modules or migration phases.
Each record states context, decision, consequences, alternatives, compatibility
impact, and review triggers.

Status values are `proposed`, `accepted`, `superseded`, or `rejected`. Phase 1
records are design decisions; they do not imply implementation.
