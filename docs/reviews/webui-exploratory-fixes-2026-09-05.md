# WebUI 开放式试用问题修复

修复分支：`fix/webui-exploratory-review`。

| 试用问题 | 修复结果 |
| --- | --- |
| 顶部选择中等却变成轻量 | 选项按模型档位区分；相同底层模型的不同档位不再冲突；显示名称去重。 |
| 首屏等待联系人刷新约 60 秒 | Gateway 立即返回已有工作区，后台刷新后通过事件更新；前端不等待 Agent 或历史完成才显示工作区；网关请求超时后展示可重试错误。 |
| QQ 离线但界面绿色“连接正常” | 显示在线数和总账号数；离线时使用警示状态；聊天页加入登录指引、重新检测和历史重试。 |
| Agent 预览失败缺少原因 | 区分历史读取失败与 Runtime 调用失败，保留可公开错误；对话和运行页可直接重试；执行路径缺失显示未确认。 |
| 搜索反馈和范围不清楚 | 区分未搜索、搜索中、无匹配、无缓存；说明只查当前浏览器缓存；侧栏文案明确匹配最新消息；验证日期先后。 |
| 联系人失败显示暂无联系人 | 未读取成功的数量显示“—”；错误状态提供重试；已有目录保留并说明是上次读取的数据。 |
| 搜索弹窗键盘操作不完整 | Esc 关闭，Tab/Shift+Tab 在弹窗内循环，关闭后恢复触发按钮焦点。 |
| 管理入口没有后续操作 | 导航标记暂不可用；群服务和内测页提供配置说明、详细诊断和重新检测；新增配置指引下载。 |
| Agent 配置密集、手机底栏拥挤 | 工具服务和全局插件维护单独折叠；手机保留五个主要入口，其余集中到更多；增大关键辅助文字。 |
| 今日摘要与实际历史范围不符 | 改为总结近期讨论，请求说明覆盖范围。 |
