## 汇总方法与范围

- 主报告按场景、架构、模块、接口、部署、验证与演进组织内容，避免按开发时间逐篇粘贴。
- 主仓源码与已存运行结果用于判断本次实现状态；设计、研究、原型和阶段记录分别保留其历史含义。
- 工作树和发布快照按逻辑路径合并。下方列出当前来源及历史独有条目，JSON 保留每个副本位置；旧副本不能覆盖当前实现。
- 原提交 PDF/Word 作为改写输入；它们与 Markdown 源稿存在内容重复。第 1、4 项旧稿已移至提交目录的 `历史版本/2026-09-06_LaTeX改写前/`；下方保留原逻辑路径，JSON 中的 `locations` 指向归档位置。
- 排除凭据、登录态、私有运行配置、聊天数据库、第三方依赖文档、自动生成数据条目，以及与作品无关的个人网站。培养方案数据集保留 README，不逐条计作设计文档。
- 本目录新生成报告不计入原始资料数量。无法读取的私有 runtime 目录不属于技术文档扫描范围。
