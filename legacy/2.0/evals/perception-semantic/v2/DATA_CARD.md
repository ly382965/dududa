# S09 Semantic v2 Schema Pilot

This bundle contains fixed synthetic 3-, 6-, and 12-turn conversation windows.
It exercises the semantic v2 schema, codec, NFC/code-point spans, Connector-backed
structural references, linguistic references, explicit uncertainty, and exact v1
downgrade behavior.

The examples are authored fixtures and contain no QQ identifiers, user messages,
credentials, model output, or externally collected data. `quality_claim` is fixed
to `schema_only`. A passing report does not establish Chinese understanding
quality, taxonomy fitness, calibration, production thresholds, or release
readiness.

Real-quality evaluation remains gated on authorized conversation-cluster data,
independent annotation and adjudication, and a held-out human-reviewed protocol.
