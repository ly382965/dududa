# Dududa 3.0

An AI companion for QQ groups, with deterministic rule handlers and a locally installed Codex CLI providing the agent harness.

The current installation instructions, architecture, migration status, and **3.0 Runtime** verification steps are maintained in the [Chinese README](README.md).

Dududa 2.0 is preserved in full under [`legacy/2.0/`](legacy/2.0/). Read the unchanged [2.0 English README](legacy/2.0/README.en.md) for historical features and deployment instructions, or the [archive record](docs/archive/2.0/ARCHIVE.md) for the frozen Git revision and recovery steps. Those historical instructions and test results do not describe the 3.0 Runtime.
