# Dududa 3.1

An AI companion for QQ groups: deterministic feature modules handle commands and automatic features, and a locally installed omp (`omp --mode rpc`) provides the agent harness.

The current feature list, architecture, setup, and verification steps are maintained in the [Chinese README](README.md); production deployment, release, and rollback are in the [operations runbook](docs/operations/v3.md).

Dududa 2.0 is preserved in full under [`legacy/2.0/`](legacy/2.0/). Read the unchanged [2.0 English README](legacy/2.0/README.en.md) for historical features and deployment instructions, or the [archive record](docs/archive/2.0/ARCHIVE.md) for the frozen Git revision and recovery steps. Those historical instructions and test results do not describe the 3.x Runtime.
