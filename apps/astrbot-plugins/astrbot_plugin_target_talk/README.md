# astrbot_plugin_target_talk

被动定向搭话插件：监听指定 QQ 号在群聊中的发言，命中概率、冷却和过滤条件后，自动 `@` 对方并调用 LLM 生成一条回复。

## 使用方式

1. 在 AstrBot 插件管理页启用插件。
2. 进入插件配置，向「特定人列表」添加目标 QQ 号。
3. 按需设置群白名单、触发概率、冷却、回复风格和提示词。
4. 保存配置并重载/重启 AstrBot。

插件不会主动开启话题；只有目标 QQ 号先在群里发言才会触发。

## 提示词变量

全局提示词和每个目标对象的提示词都支持这些变量：

- `{target_alias}`：目标别名，未配置时使用群昵称或 QQ 号
- `{target_qq}`：目标 QQ 号
- `{group_id}`：群号
- `{sender_message}`：目标刚刚发送的消息
- `{reply_style}`：回复风格
- `{recent_context}`：最近群聊上下文
- `{max_reply_chars}`：回复字符上限
