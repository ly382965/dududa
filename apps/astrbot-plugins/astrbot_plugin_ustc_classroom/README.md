# astrbot_plugin_ustc_classroom

USTC 教室空闲与考试安排查询插件。数据来自 catalog.ustc.edu.cn 公开 API。

## 触发方式

**@bot 自然语言**（先于 2.0 Runtime 处理，priority=300）：

- `@杨小柠 2304教室今天下午空闲吗` → 是否占用、谁占用
- `@杨小柠 5101 周三上午有人吗` → 排课占用明细
- `@杨小柠 概率论考试在哪考` → 考试时间与地点

**命令**：

- `/教室 2304 今天下午`
- `/考试 概率论`

## 数据与缓存

- 学期/课程/考试列表来自 catalog.ustc.edu.cn（无需校园网）
- 课程排课缓存 12 小时（官方数据次日更新）
- 周次按学期起始日推算（第一周周一 = 起始日所在周的周一）
