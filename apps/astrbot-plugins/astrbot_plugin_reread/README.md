# astrbot_plugin_reread

来自 Dududa 1.0 的轻量群聊自动复读插件，固定上游版本见仓库根目录
`THIRD_PARTY_NOTICES.md`。

功能：

- 文本、图片、QQ 表情分别设置阈值；
- 可要求连续消息来自不同用户；
- 支持复读概率和“打断！”概率；
- 每个群维护独立的内存窗口，不调用 LLM。

插件由 AstrBot 事件入口执行。管理员控制台负责给每个群设置是否启用；AstrBot
插件配置保留阈值、概率和群白名单等执行参数。

为避免挂载插件后在所有群意外发送，插件全局开关默认关闭。当前 WebUI 会保存
会话级期望；在 AstrBot 消费该策略的 Adapter 接通前，不能把“已配置”视为已在线执行。
